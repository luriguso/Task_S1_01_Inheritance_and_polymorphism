# 🧠 Java OOP Exercise Series – Inheritance, Interfaces & Polymorphism

---

## 📄 Description – Exercise Overview

This repository contains the solution to a series of structured Java exercises aimed at reinforcing core **Object-Oriented Programming (OOP)** principles such as **inheritance**, **interfaces**, **polymorphism**, and **class design**.

The exercises progress across three levels, from basic inheritance to more advanced class structures with business rules and console interaction.

> ⚠️ Development must be done in **Eclipse** or **IntelliJ IDEA**.  
> ✅ Code must follow **best practices** outlined in Sprint 0.  
> ✅ Exercises can be built using **Maven**, **Gradle**, or plain Java.  
> ✅ All code must be written in **English**.

---

## 🎯 Objectives

- Learn to correctly apply **Object-Oriented Programming (OOP)** principles.
- Understand and implement **inheritance**, **abstraction**, **interfaces**, and **static/final modifiers**.
- Practice clean code and class responsibilities in Java.

## 🛠️ Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/luriguso/Task_S1_01_Inheritance_and_polymorphism.git
   cd Task_S1_01_Inheritance_and_polymorphism
   ```

2. Open the project in your IDE:
   - **Eclipse**: File → Open Projects from File System
   - **IntelliJ**: File → Open → Select project folder

3. If using Maven/Gradle, import dependencies or run:
   ```bash
   mvn clean install
   ```

## 🧩 Exercise Levels Overview

### 🔹 Level 1
#### 🔹 Exercise 1
- Abstract class `Instrument` and its subclasses (`Wind_instrument`, `Stringed_instrument`, `Percussion_instrument`)
- Demonstrates static blocks and class loading
- Understanding `static`, `final`, and `static final` attributes
#### 🔹 Exercise 2
- Class `Car`
- Understanding `static`, `final`, and `static final` attributes

### 🔹 Level 2
- Interfaces `Camera`, `Clock` and class hierarchy `Phone → Smartphone`
- Implementing static vs non-static methods and how to call them

### 🔹 Level 3
- Abstract class `News` and its subclasses (`Football_news`, `Basketball_news`, `Tennis_news`, `F1_news`, `Motorcycle_news`)
- Demonstrates static blocks and class loading
- Understanding `static`, `final`, and `static final` attributes

- Complete object-oriented structure: `News`, `Journalist`, `Sports`
- News pricing and scoring rules based on content
- Interactive console menu (CRUD operations, calculations)
